# TPW Data Templates

These CSV templates are structured to receive verified data from Austin city sources, open data portals, and direct department requests. Each file maps to a key section of the TPW Master Briefing Packet.

| File | Analysis Section | Primary Data Source |
|---|---|---|
| budget_capital_spending.csv | Section 2: Budget | Austin Finance Online, adopted budget |
| infrastructure_condition.csv | Section 3: Infrastructure | TPW Open Records, 311 data |
| vision_zero_safety.csv | Section 4: Vision Zero | CRIS crash database, TPW safety reports |
| drainage_flood.csv | Section 5: Drainage | Watershed Protection Dept, FEMA |
| equity_service_distribution.csv | Section 6: Equity | ACS, 311 data, capital project GIS |

Populate from sources listed in `TPW_Austin_Data_Sources_and_Citations_Appendix.md`.
