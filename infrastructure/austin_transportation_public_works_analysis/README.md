# Austin TPW — Transportation & Public Works

## Purpose
Policy briefings, data templates, and stakeholder materials for the City of Austin Transportation and Public Works Department.

## Contents
- `TPW_Austin_*` — Council briefing packets, executive handouts, stakeholder QA, slide outlines, data citations
- `TPW_Data_Templates/` — CSV templates (capital spending, drainage, equity, infrastructure condition, Vision Zero)
- `austin-tpw-analysis.html` — Full analysis dashboard
- `TPW_Austin_Policy_Recommendations.html` — Policy recommendations report
