# Config Folder

This folder contains configuration files used by scripts in `scripts/`.

## Files

- `analysis_config.yaml`: source file mapping and scoring settings for baseline analysis.
- `geospatial_config.yaml`: geospatial file mapping and spatial join settings.

## Usage Notes

- Update config values here instead of hardcoding paths in scripts.
- Keep filenames and keys stable to preserve reproducibility.
