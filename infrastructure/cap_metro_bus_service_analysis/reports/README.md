# Reports Folder

This folder contains narrative outputs, policy summaries, and presentation-support materials.

## Subfolders

- `presentation_versions/`: audience-specific slide scripts and outlines.

## Key Files

- `Baseline_Evidence_Report.md`: primary synthesis report.
- `CMTA_20_Minute_Presentation_Pressing_Concerns.md`: 20-minute presentation script.
- `CMTA_20_Minute_Presenter_Cheat_Sheet.md`: condensed presenter notes.
- `311_Unresolved_Burden_Summary.md`: unresolved 311 burden summary with North Lamar escalation guidance.

## Usage Notes

- Use files here for communication and decision support.
- Use `output/tables/` and `output/figures/` as evidence references when updating report text.
