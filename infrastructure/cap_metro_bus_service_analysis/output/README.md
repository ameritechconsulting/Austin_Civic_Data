# Output Folder

This folder stores generated analysis artifacts.

## Subfolders

- `tables/`: CSV outputs used for findings, QA checks, and slide metrics.
- `figures/`: chart images generated from pipeline scripts.

## Usage Notes

- Contents are generated; do not manually edit output files unless doing one-off review work.
- Re-generate using `bash scripts/run_all.sh`.
