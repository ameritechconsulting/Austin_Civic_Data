# External Reports Data

This folder stores external agency documents and claim extracts used for cross-validation and narrative evidence checks.

## Expected Structure

- pdf/: source PDF documents for extraction.
- Derived outputs are written to output/tables/ by extraction scripts.

## Usage Notes

- Keep original documents unchanged for provenance.
- Use scripts/extract_external_pdf_claims.py for reproducible extraction.
