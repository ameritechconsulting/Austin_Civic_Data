# Canonical Data

This folder contains active, pipeline-ready datasets used by analysis scripts.

## Usage Notes

- Treat this folder as the source of truth for current runs.
- Keep schema and filenames aligned with config/analysis_config.yaml.
- Add new datasets here only when they are part of the active workflow.
