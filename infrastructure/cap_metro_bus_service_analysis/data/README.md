# Data Folder

This folder holds active inputs, references, and external materials used by the analysis pipeline.

## Subfolders

- `canonical/`: active core datasets used by baseline scripts.
- `geo/`: geospatial boundary files and geospatial input notes.
- `external_reports/`: external PDF and supplemental report inputs.
- `reference/`: supporting files not required for every run.

## Usage Notes

- Treat `canonical/` as the authoritative data source for current runs.
- Keep file names consistent with `config/analysis_config.yaml`.
