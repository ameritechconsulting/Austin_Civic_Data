# Austin Civic Data

Research, analysis, and reporting on Austin, Texas public policy across five topic areas.

## Data Sources

Primary data sources include City of Austin Open Data Portal, U.S. Census Bureau / ACS, CapMetro GTFS feeds,
Austin 311 Service Requests, and City of Austin adopted budget documents.
See individual project folders for source citations.
