# Methodology

## Overview

All analyses in this repository use publicly available data from official government sources.
No personally identifiable information (PII) is included.

## Data Sources

- **City of Austin Open Data Portal** — data.austintexas.gov
- **U.S. Census Bureau / American Community Survey (ACS)** — census.gov
- **CapMetro GTFS & open feeds** — capmetro.org
- **Austin 311 Service Request Data** — data.austintexas.gov
- **City of Austin Adopted Budget Documents** — austintexas.gov/budget
- **Austin Code / Permit Data** — austintexas.gov

## Data Processing Standards

- Raw data is preserved unmodified in `data/raw/` folders within each project
- Cleaned and processed versions are kept separate in `data/cleaned/` and `data/processed/`
- All transformations are documented in project-level README files or analysis scripts

## Analysis Standards

- Statistical methods are described within each project's analysis files
- Assumptions and limitations are noted in project reports
- Geographic boundaries follow City of Austin Council District definitions (10 districts)

## Accuracy and Limitations

All findings reflect the data available at the time of analysis.
Data may be subject to revision by the originating agency.
Projections and estimates carry inherent uncertainty and should not be used as sole basis for policy decisions.
